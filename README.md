# BillManage

本地票据管理工具。按项目上传 PDF/图片，自动 OCR 识别后确认归档，再一键根据 `报销单模版.xlsx` 生成可下载的报销单。

## 推荐流程

1. **上传票据**  
   在项目页上传 PDF、PNG、JPG 或 WebP。系统立即 OCR：
   - 电子 PDF 优先读文本层；
   - 扫描件/图片走本机 Tesseract。

2. **核对并归档**  
   左侧预览，右侧直接改正票据类型、金额、日期、行程/销售方、发票号码。  
   点“确认并自动归档”后：
   - 文件按项目和月份重命名归档；
   - 状态变为“未报销”，可以进入报销单。

3. **勾选票据，二联打印或生成报销单**
   在票据列表左侧勾选已确认归档的票据（可全选/清空）：
   - 点“A4 二联打印”可生成 PDF；系统自动裁去原件大块白边，每张 A4 上下排列两张票据，并在中间加入裁切虚线；
   - 打印时选择 **A4、纵向、实际大小（100%）**；
   - 历史报销批次也可随时重新生成二联打印版。

   再点“生成并提交报销单”：
   - 读取根目录 `报销单模版.xlsx`；
   - 自动填写出差日期范围、出差地点、项目名称；
   - 按票据逐行填写费用类别、行程/明细、金额、日期、发票号码；
   - 票据超过模板 3 行时自动扩行，并写入合计金额；
   - 生成 Excel 后进入“待确认”批次，可下载检查。

4. **确认报销结果**  
   - 全部成功：确认后票据锁定为“已报销”；
   - 部分退回：勾选退回票据，它们会回到未报销，可改完再生成；
   - 也可直接“撤回报销单”，全部恢复未报销。

5. **历史可下载，已报销只读**  
   - 页面底部保留报销单记录，确认后仍可重复下载；
   - 每个批次支持“打包导出”，压缩包内按用途分为“打印文件”和“原始文件”：打印文件包含报销单 Excel 与 A4 二联排版 PDF，原始文件包含按整理后名称归档的全部票据；
   - 已提交/已报销票据不能修改、删除或重新识别。

## 启动

```bash
UV_CACHE_DIR=.uv-cache uv sync
UV_CACHE_DIR=.uv-cache uv run uvicorn main:app --reload
```

打开 `http://127.0.0.1:8000`。

数据目录：
- `data/billmanage.db` 数据库
- `data/pending` 待确认原件
- `data/archived` 已归档原件
- `data/reimbursements` 生成的报销单

## OCR 说明

电子发票、铁路电子客票等 PDF 通常带文本层。扫描件依赖系统 `tesseract`，建议安装 `chi_sim` 中文语言包。程序会自动选用已安装的 `chi_sim`、`eng`、`snum`。
